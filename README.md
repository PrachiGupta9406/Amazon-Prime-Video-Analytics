# Amazon Prime Video Analytics Dashboard

## Project Overview

Built an interactive Power BI dashboard to analyze Amazon Prime Video content, ratings, genres, and release trends.

## Tools Used

* Power BI
* Excel
* DAX

## Key Insights

* Genre Distribution Analysis
* Ratings Analysis
* Movies vs TV Shows Comparison
* Country-wise Content Analysis
* Release Trend Analysis
